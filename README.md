# 웨이어블 (WAYABLE)

> 가장 가까운 길이 아니라, **실제로 갈 수 있는 길**을 안내합니다.

웨이어블은 휠체어 사용자와 보행이 불편한 이동약자를 위한 접근성 경로 안내 서비스입니다.  
일반 지도에서 하나의 길로 표시되더라도 실제 현장에는 계단, 급경사, 턱, 좁은 보행 공간이 존재할 수 있습니다. 웨이어블은 이러한 이동 조건을 경로별로 보여주고, 사용자가 자신의 상황에 맞는 길을 직접 선택하도록 돕습니다.

## 배포 사이트

**[웨이어블 데모 바로가기](https://gable-freepark.halwaysblue.chatgpt.site)**

모바일 화면에 최적화된 프로토타입입니다.

## 문제 정의

청일조계지 경계계단에서 자유공원까지 직접 이동하며 현장을 조사했습니다.

일반 지도에서는 약 5분 거리로 표시되지만, 실제 최단 경로에는 계단 35개 단이 존재했습니다. 다른 경로에도 급경사나 좁은 보행 공간이 있어 이동약자에게는 단순한 불편이 아니라 **이동 불가능**으로 이어질 수 있었습니다.

기존 길찾기가 주로 시간과 거리만 비교한다면 웨이어블은 다음 질문에 답하고자 합니다.

- 이 경로에 계단이나 턱이 있는가?
- 경사가 이동 가능한 수준인가?
- 휠체어가 지나갈 보행 공간이 확보되어 있는가?
- 사용자의 이동 조건에 가장 적합한 경로는 무엇인가?

## 핵심 기능

### 1. 현장 검증 장애물 정보

지도 위 장애물 마커를 누르면 현장에서 직접 확인한 계단 사진과 위치, 위험도를 확인할 수 있습니다.

### 2. 장애물 회피 경로 탐색

`피해가기` 버튼을 누르면 계단, 경사, 턱, 보행 공간을 기준으로 대체 경로를 탐색하는 흐름을 체험할 수 있습니다.

### 3. 세 가지 경로 비교

| 경로 | 특징 | 예상 시간 | 거리 | 접근성 점수 |
|---|---|---:|---:|---:|
| Route A | 계단 없는 완만한 우회 경로 | 8분 | 520m | 92점 |
| Route B | 빠르지만 급경사가 있는 우회 경로 | 6분 | 430m | 73점 |
| Route C | 계단이 포함된 기존 최단 경로 | 5분 | 350m | 45점 |

단순히 하나의 정답 경로를 강요하지 않고 각 경로의 조건을 투명하게 보여줍니다. 사용자는 자신의 이동 능력과 상황에 따라 최종 경로를 선택할 수 있습니다.

### 4. 경로 안내 시뮬레이션

경로를 선택하면 다음 방향, 남은 시간과 거리, 경로 상태를 표시하며 지도 위 현재 위치가 이동하는 내비게이션 화면으로 전환됩니다.

### 5. 접근성을 고려한 모바일 UI

큰 터치 영역, 명확한 색상 구분, 핵심 정보 중심의 카드 구조를 적용해 현장에서 빠르게 판단할 수 있도록 설계했습니다.

## 사용 흐름

1. 청일조계지에서 자유공원까지의 기본 최단 경로를 확인합니다.
2. 지도 위 계단 장애물 마커를 선택합니다.
3. 현장 사진과 위험 정보를 확인한 후 `피해가기`를 누릅니다.
4. Route A, B, C의 시간·거리·장애물·접근성 점수를 비교합니다.
5. 사용자에게 적합한 경로를 선택하고 안내를 시작합니다.

```bash

cd Incheon-GDG-Hackton
python3 -m http.server 8000
```

## 현재 구현 범위

현재 버전은 청일조계지–자유공원 구간을 대상으로 서비스 가치를 검증하는 **현장 조사 기반 MVP 데모**입니다.

- 경로와 접근성 점수는 현장 조사 결과를 바탕으로 구성한 데모 데이터입니다.
- 지도, GPS, 실시간 교통 데이터는 아직 연동하지 않았습니다.
- 내비게이션의 현재 위치 이동은 실제 GPS가 아닌 UI 시뮬레이션입니다.
- AI 분석 화면은 향후 기능의 사용자 경험을 표현한 프로토타입입니다.

## 향후 확장 방향

### Phase 1. 사용자 맞춤 접근성 경로

사용자 유형과 이동 조건을 선택할 수 있도록 확장합니다.

- 수동 휠체어, 전동 휠체어, 목발, 보행 보조기, 유아차 등 유형 선택
- 계단 회피, 최대 허용 경사, 최소 보도 폭 등 개인 조건 설정
- 사용자 조건에 따른 경로별 접근성 점수 재계산
- 안전 우선, 거리 우선, 시간 우선 등 탐색 기준 제공

### Phase 2. 실제 지도와 위치 데이터 연동

- Kakao Maps 또는 Naver Maps API 기반 실제 지도 제공
- GPS를 이용한 현재 위치와 목적지 탐색
- 도로망을 그래프로 변환한 접근성 최적 경로 계산
- 경로 이탈 시 접근 가능한 대체 경로 재탐색
- 장애인 주차장과 안전한 승하차 지점 안내

### Phase 3. 현장 데이터 자동화

- 공공데이터의 경사로, 엘리베이터, 장애인 편의시설 정보 연동
- 스마트폰 센서와 GPS를 활용한 경사도 및 이동 환경 수집
- 이미지 분석을 통한 계단, 턱, 노면 파손, 보도 폭 후보 감지
- 데이터의 촬영 시각과 검증 상태 표시

### Phase 4. 시민 참여형 접근성 지도

- 사용자가 장애물 사진과 위치를 직접 제보
- 중복 제보 통합 및 신뢰도 점수 계산
- 관리자 또는 지역 커뮤니티의 현장 검증
- 공사, 적치물, 엘리베이터 고장 등 일시적 장애물 실시간 반영

### Phase 5. 지역 단위 서비스 확장

- 인천 개항장·차이나타운 관광 동선으로 조사 범위 확대
- 관광지, 공공기관, 병원, 지하철역의 접근 가능한 출입구 연결
- 지자체용 접근성 취약 구간 대시보드 제공
- 축적 데이터를 활용한 보행환경 개선 우선순위 제안

## 기대 효과

- 이동약자에게 실제 이동 가능성을 반영한 경로 선택권 제공
- 관광지 방문 전 이동 위험을 예측해 불필요한 우회와 이동 포기 감소
- 현장 조사와 시민 제보를 통해 기존 지도에 없는 접근성 데이터 축적
- 지자체가 계단, 급경사, 좁은 보도 등 개선이 필요한 구간을 데이터로 파악

## 차별점

웨이어블의 핵심은 단순한 “무장애 경로 추천”이 아닙니다.  
경로별 장애물과 판단 근거를 함께 공개하여 사용자가 자신의 상황에 맞는 길을 선택하도록 돕는 **설명 가능한 접근성 내비게이션**입니다.
